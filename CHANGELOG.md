# Changelog

## 1.0.0

- Choose Hardcore grave protection to keep carried items in a recoverable grave while retaining Hardcore skill penalties.
- Remove Corpse Run and No skill drain while grave protection is enabled.
- Enable the Cartography Table map separately: M opens your last saved table map, with no minimap or player/ship markers.
- Turn signs into pins, choose their icons, and cross them off. Record at a Cartography Table to publish changes.
- Require compatible Den's Hardcore versions on the server and all players' PCs.
- Keep vanilla Hardcore world settings so the world can run regular Hardcore when the mod is absent.
- Rename the mod to Den's Hardcore and use the Corpse Run icon.
- Configure both world options through BepInEx or the host's world-modifier checkboxes.
