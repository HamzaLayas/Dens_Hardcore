# Changelog

## 1.2.7

- Use Shift+E to add or remove sign pins, Ctrl+E to cycle icons, and Ctrl+Shift+E to cross or uncross pins by default.
- Allow icon changes without holding Shift or opening the sign text editor.
- Update sign hints and configuration descriptions for the new shortcuts. Existing settings are preserved; set `Sign cross modifier = LeftShift` to use the new default.
