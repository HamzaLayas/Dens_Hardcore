# Changelog

## 1.2.0

- Use the existing No map checkbox for the Cartography Table map and the Hardcore death-penalty option for Den's death rules. No extra world-modifier rows are added.
- Existing No map and Hardcore death selections now enable their replacements by default. Administrators can disable either replacement in BepInEx configuration.
- Adjust skill loss, item recovery, death buffs, and the default sign-pin icon. Players can hide the saved-map banner.
- Install with the renamed Dens_Hardcore DLLs and smaller install packages. Remove old CartographyMap plugin DLLs when upgrading; keep your configuration and saved map data.
- Update the server and every player's mod together.
