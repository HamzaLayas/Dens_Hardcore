# Changelog

## 1.4.1

- Make abandoned-boss despawning more reliable: a boss summoned at an altar is now recognized as soon as it appears, so it cannot be missed on some game setups.
- Bosses already summoned with 1.4.0 keep despawning as before.
- Versions before 1.4.1 cannot join 1.4.1 worlds, and 1.4.1 cannot join worlds running an earlier version.
