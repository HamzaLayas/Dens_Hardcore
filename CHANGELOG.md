# Changelog

## 1.3.3

- Change the default `Open sea coast margin` to 45 metres. Swamps stay hidden and more sea near coasts is shown, so landmasses no longer look oversized. Existing worlds keep their saved value; set `Open sea coast margin = 45` in a world's section to use the new default.
- Explain in the configuration and player guide that the margin rounds up to 12 metre map steps.
- Versions before 1.3.3 cannot join 1.3.3 worlds, and 1.3.3 cannot join worlds running an earlier version.
