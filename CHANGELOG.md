# Changelog

## 1.3.2

- On the Cartography Table map, reveal only open sea. Fog now stays over coastal waters, swamps, rivers, and lakes, so shorelines and swamps are no longer visible before you explore them.
- Hosts can set how far from land water stays fogged with `Open sea coast margin` (0 to 1000 metres, default 125).
- Versions before 1.3.2 cannot join 1.3.2 worlds, and 1.3.2 cannot join worlds running an earlier version.
